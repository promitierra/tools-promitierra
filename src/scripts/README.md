# Scripts para Tareas Temporales

Esta carpeta contiene scripts para tareas temporales o de procesamiento por lotes que no forman parte del núcleo de la aplicación.

## Propósito

- Almacenar scripts de utilidad para procesamiento puntual de datos
- Proporcionar herramientas para tareas administrativas o de mantenimiento
- Implementar pruebas de concepto antes de integrarlas en la aplicación principal

## Convenciones

- Cada script debe tener un propósito claro y documentado
- Incluir nombre del autor y fecha de creación en cada script
- Usar el prefijo `temporal_` para scripts de uso único
- Documentar dependencias específicas si son diferentes a las de la aplicación principal
