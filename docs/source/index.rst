Características Principales
-------------------------

* Redimensionamiento de PDFs a tamaño carta
* Conversión de imágenes a PDF
* Conversión de PDF a imágenes PNG
* Creación automática de estructura de carpetas
* Interfaz gráfica moderna y amigable
